Document 4: Sensor Integration

Purpose
Enable automated workout data input from sensors to reduce manual entry and improve accuracy.

Sensor Types & Integration Flow

RFID → Detect weight plates → Send JSON to Flask.
Gyroscope/Accelerometer (MPU6050 + ESP32) → Detect movement → Send JSON via Wi-Fi.
Camera (MediaPipe/OpenCV) → Count reps → Send JSON.
Smartwatch → Send movement data via REST API.

✅ Camera Integration (Python + MediaPipe)
Pythonimport cv2import mediapipe as mpimport requestsAPI_URL = 'http://localhost:5000/add'mp_pose = mp.solutions.posepose = mp_pose.Pose()cap = cv2.VideoCapture(0)reps = 0while cap.isOpened():    ret, frame = cap.read()    results = pose.process(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))    if results.pose_landmarks:        # Simple logic: detect squat position change        hip_y = results.pose_landmarks.landmark[mp_pose.PoseLandmark.LEFT_HIP].y        if hip_y < 0.5:  # Squat down            reps += 1            data = {'date': '2026-01-18', 'exercise': 'Squat', 'reps': reps, 'weight': 80}            requests.post(API_URL, json=data)    cv2.imshow('Workout Tracker', frame)    if cv2.waitKey(10) & 0xFF == ord('q'):        breakcap.release()cv2.destroyAllWindows()Show more lines
