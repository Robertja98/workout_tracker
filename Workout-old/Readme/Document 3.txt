Document 3: Tablet UI

Purpose
Create a tablet-friendly interface for logging workouts and viewing progress:

Responsive design using Bootstrap.
Large buttons for quick input.
Minimal typing during workouts.
AJAX calls to Flask API using JSON.


UI Features

Workout Form:

Date picker.
Dropdown for exercise selection.
Numeric input for reps and weight.
Large “Add Workout” button.


Dashboard:

Table of logged workouts.
Charts for progress visualization (future integration with Chart.js).




Responsive Design Principles

Use Bootstrap grid system for layout.
Apply large button classes (btn-lg) for touch-friendly UI.
Ensure font scaling for readability on tablets.
