Testing Checklist
✔ Verify /add route accepts JSON and writes to CSV.
✔ Confirm /dashboard displays updated data.
✔ Test UI on tablet (responsive layout).
✔ Validate sensor scripts send correct JSON payloads.
✔ Check CSV file integrity after multiple writes.

Debugging Common Issues

CORS errors: Add Flask-CORS if needed.
File permission issues: Ensure data/workouts.csv is writable.
Sensor connectivity: Check Wi-Fi credentials and API URL.
